# 镜头 JINGTOU STUDIO

当前交付为本地运行版本，未推送源码或发布远程版本。

面向个人创作者的动漫短剧工作台。首版按照「创建作品 → 建立角色和场景 → 编辑分镜与对白 → 生成候选图和配音 → 选图 → 单镜头重做 → 成片预览」实现。

## 本地运行

需要 Node.js 22.13 或更高版本，推荐 Node.js 24。

```bash
npm ci
npm run dev
```

打开命令输出的 Local 地址。端口默认 3000，被占用时会自动使用下一个端口。首页无需登录即可访问，保持原有介绍和「浏览样例」入口。右上角可打开登录、注册弹窗，注册成功即可开始创作，暂不需要邮箱验证。创建作品、进入个人作品或复制样例时需要登录；内置样例可以直接只读浏览。本地账号、作品数据库和上传图片保存在 `.wrangler/`，请保留此目录以恢复创作进度。首次请求会自动创建所需数据表。

### 账号与数据归属

- 首页右上角提供「登录」「注册」按钮，通过弹窗完成认证；关闭弹窗可继续浏览首页或样例。进入个人功能时提示登录，登录后返回所选页面。
- 邮箱忽略大小写和首尾空格，密码为 8–128 个字符。注册后自动登录，登录状态最长保留 30 天；侧边栏显示当前邮箱并提供退出入口，退出前先保存正在编辑的作品。
- 每个账号拥有自己的作品、角色、场景、上传图片和生图结果。未登录无法访问个人数据，知道他人的作品或图片地址也不能读取；内置样例可以公开只读浏览。
- 密码使用加盐 scrypt 哈希保存；会话令牌保存在 HttpOnly Cookie，数据库仅存令牌摘要。支持退出吊销、会话过期、跨标签页账号切换及重复登录尝试限制。
- 当前不发送验证邮件，也不提供邮件找回密码。生图与配音服务配置由服务端统一设置，所有账号共用已配置的服务商。
- localhost 与局域网 IP 是不同的浏览器站点，可能需要分别登录；同一邮箱登录后看到的是同一份账号数据。

旧版共享作品继续保留在原来的 `local-development` 归属下，不会自动交给第一个注册用户。要迁移到自己的账号，先在页面注册邮箱，再停止开发服务器，在项目目录运行：

```bash
# 查看将迁移的作品、图片数量，不修改数据
npm run data:migrate -- your-email@example.com
# 确认后执行；自动在 .wrangler/backups/ 备份数据库
npm run data:migrate -- your-email@example.com --apply
npm run dev:lan
```

迁移会在同一事务中修改旧作品和图片的归属，保留角色、场景、分镜、选图及图片地址。目标账号必须已注册，重复执行不会复制作品，也不会修改其他账号的数据。

### 局域网访问

停止已有的开发服务器，再启动局域网模式：

```bash
npm run dev:lan
```

其他设备连接同一局域网后，打开终端输出的 Network 地址，例如 `http://192.168.1.112:3000`；IP 随本机网络变化，端口以实际输出为准。本机仍可用 `http://localhost:3000`。服务需要保持运行；如果其他设备无法连接，请检查系统防火墙是否允许 Node.js 接入，以及路由器是否启用了访客网络隔离。

局域网内的访问者需要分别注册、登录，仅能访问各自账号的数据；样例原稿仍然只读。停止后改用 `npm run dev` 即恢复仅本机访问。

`dev:lan` 只改变服务监听地址，不会绕过账号认证。角色、分镜和候选图 ID 兼容局域网 HTTP 页面。

## 生图接口配置

没有密钥时，作品、角色、上传、选图、排序、字幕和预览均可使用；点击生成会提示配置服务，不会用示例图冒充实际生成结果。

复制配置示例：

```bash
cp .env.example .dev.vars
```

在本地 `.dev.vars` 中设置以下字段，完成后重启开发服务器：

```dotenv
IMAGE_API_KEY=你的服务端密钥
IMAGE_API_BASE_URL=https://new-nocf.97api.com/v1
IMAGE_MODEL=gpt-image-2
```

当前本地配置接入 97API 的 newapi 1K 廉价生图直连入口，基础地址为 `https://new-nocf.97api.com/v1`，模型为 `gpt-image-2`。把令牌填入 `.dev.vars` 的 `IMAGE_API_KEY` 后重启服务。不要把 `/images/generations` 或 `/images/edits` 写进基础地址，程序会按镜头是否带角色或场景参考图自动选择端点。

也支持 `OPENAI_API_KEY`，但 `IMAGE_API_KEY` 优先。不要把密钥写进前端代码、提交到 Git 或发到聊天里。`.dev.vars` 和 `.env` 已被忽略。

接口约定：

- 关联角色或已选场景图的镜头：调用 `${IMAGE_API_BASE_URL}/images/edits`，multipart 字段为 `model`、`prompt`、`n` 和可重复的 `image`。按角色参考图、场景参考图的顺序传送真实文件内容，提示词中的图片编号与之对应。
- 没有关联参考图的镜头，以及独立场景生成：调用 `${IMAGE_API_BASE_URL}/images/generations`。97API 请求使用 `model`、`prompt`、`size=1254x1254`、`quality=high`、`output_format=webp`、`n=1` 和 `response_format=url`。
- 图生图按兼容接口请求 base64；97API 文生图返回外部 HTTPS 图片 URL。服务端下载并校验 PNG、JPEG 或 WebP 后保存到本地素材库，拒绝本机、局域网域名和 IP 直连地址。
- 每次生成 1–4 张候选图。程序会并行发起对应数量的单图请求，每个请求的 `n` 固定为 `1`。生成后不自动改变已有选图；失败会保留已有素材，可重试。
- 每个关联角色都必须有参考图。角色设定变化只影响后续生成；不关联角色的镜头不会在提示词中声称已经提供参考图。

线上配置通过 Sites 的服务端环境变量完成，不会从本地配置文件上传密钥。

## 配音接口配置

配音服务通过独立 provider 接口接入阿里云百炼 Qwen。角色只保存女声或男声这个逻辑选项，具体音色由 provider 映射；当前分镜的对白同时作为字幕与合成文本。

默认接入 `qwen3-tts-flash`。先在百炼控制台取得北京地域的 API Key，然后写入本地 `.dev.vars`：

```dotenv
DASHSCOPE_API_KEY=你的百炼 API Key
QWEN_TTS_MODEL=qwen3-tts-flash
QWEN_TTS_FEMALE_VOICE=Momo
QWEN_TTS_MALE_VOICE=Moon
```

保存后重启开发服务器。服务端调用 `https://maas.qianwenaiapi.com/api/v1/services/aigc/multimodal-generation/generation`，立即下载接口返回的临时 WAV；验证文件后保存到当前账号的私有素材库。临时下载仅接受北京 OSS 域名，不会请求任意外部地址。单个镜头对白最多 600 个字符。模型、接口参数和可用音色以[阿里云 Qwen-TTS API](https://help.aliyun.com/zh/model-studio/qwen-tts-api)、[`qwen3-tts-flash` 模型说明](https://help.aliyun.com/zh/model-studio/qwen3-tts-flash)与[官方音色列表](https://help.aliyun.com/zh/model-studio/qwen-tts-voice-list)为准。

Qwen 默认女声为 `Momo`、男声为 `Moon`，可通过对应环境变量调整。密钥只由服务端读取，不会返回前端。达到服务商限额或调用失败时，页面会保留上一版配音并允许重试。

生成配音前需要填写对白、将角色加入当前镜头，并选择说话角色。修改对白或角色音色后，旧音频仍然保留并标记为需要更新，用户决定何时重新生成；如果把说话角色换成相同音色的另一角色，现有音频仍可继续使用。预览会跳过过期或缺失的配音；配音短于镜头时剩余时间静音，长于镜头时在下一个镜头开始时切换。

## 首版功能

- 邮箱密码注册登录、会话恢复与退出；每个账号独立保存作品和素材，暂不验证邮箱。
- 多作品创建、打开、修改名称、简介、画幅和画风；可在分镜工作台删除保存的作品，内置样例固定只读且不可删除。
- 左侧角色库汇总所有作品中的角色，并显示所属作品、参考图、音色和镜头使用数；进入所属作品后可创建、编辑、删除角色，选择女声或男声，并管理多张参考图。
- 左侧场景生成汇总所有作品中的场景，并显示所属作品、预览图、画风、候选图和镜头使用数；进入所属作品后可选择风格预设或输入自定义风格生成纯环境图。
- 分镜新增、删除、拖动排序及上下移动；名称、出场角色、说话角色、场景、画面描述、对白、时长编辑。
- 候选图生成与手动上传、放大浏览、双图比较、随时更换成片画面。
- 单镜头重做保留历史候选图和当前选图；明确展示生成中、生成失败、待生成、待选图状态。
- 单镜头配音生成与重做；失败时保留上一版 WAV，修改对白或角色音色后提示更新。
- 按最新顺序和时长播放选定画面、字幕与配音；支持播放、暂停、进度拖动、镜头跳转和静音；缺失画面或配音占用原有时间位置并显示提示。
- 自动保存、失败重试、离开页面时未保存提醒、乐观并发检查；遇到其他会话修改会提示重新加载。

首版不包含人物连续动作、背景音乐、音效、声音克隆、复杂运镜或视频导出。每个镜头仅支持一位说话角色和一段对白。候选图每镜头最多 200 张，角色参考图最多 20 张，单张上传不超过 10 MB。

## 场景生成与分镜复用

在作品编辑顶部进入「场景生成」，创建场景并填写地点、布局、建筑、光线等描述。场景默认带入作品画风，也可选择预设或输入自定义风格，再生成 1–4 张候选图或上传图片。点击「选用」确定参考图后，在「分镜台 → 镜头设定 → 关联场景」选择该场景；原有「场景」文字仍可作为补充说明。

同一场景可关联多个分镜。生成分镜时使用最新场景设定与选图，并一并携带角色参考图；关联场景尚未选图时会提示先选图。场景改图、重做或删除不改变已有分镜素材。删除场景仅解除分镜中的场景关联。每个作品最多 100 个场景，每个场景最多 200 张候选图。

场景与生成状态保存在同一个作品文档中，图片沿用本地 R2 存储。老作品会加载为空场景库，无需手动迁移。场景生成失败可重试；刷新后可恢复生成状态；样例原稿仍然只读。

## 示例作品

样例原稿只读，可以查看角色、分镜、放大比较候选图与预览成片。浏览不会创建作品或触发自动保存；保存、删除、生成接口也会拒绝修改原稿。点击「复制为我的作品」后，会创建独立副本并跳转到副本地址，可自由编辑与保存。此前通过「体验示例作品」创建的已有副本及其修改会保留，仍然可以编辑。

《夏日来信》包含林夏、陈屿两个角色，12 个五秒镜头。使用三张原创 AI 示例素材编排为 60 秒时间线，所有示例图片都标记为「示例」，用于验证交互流程。它不是十二个独立镜头的真实生成验收结果。

示例图：`public/samples/summer.png`、`linxia.png`、`chenyu.png`；分享卡：`public/og.png`。图片使用内置 imagegen 生成。构图提示为「夕阳下的夏日海边车站，深蓝短发、珊瑚发带、米白上衣、青绿裙子的女主与棕色短发、米白衬衫、深蓝背包的男主重逢」；两张特写以原场景为参考，分别强调女主握着信封和男主温柔微笑。分享卡使用品牌文案「镜头」「让故事，一帧帧发生。」和深灰、浅绿配色。

## 技术与数据

- React 19、TypeScript、Vinext/Vite，Cloudflare Worker 兼容输出。
- D1 的 `projects` 表保存有版本号的作品文档，`assets` 表保存图片与 WAV 元数据；R2 保存图片和配音原始内容。
- `auth_users` 保存账号及密码哈希，`auth_sessions` 保存会话摘要及到期时间，`auth_attempts` 记录限时登录尝试。作品和素材的 `owner` 使用服务端会话取得的用户 ID，不接受客户端指定身份，也不再使用共享开发身份或 `oai-authenticated-user-email` 作为账号认证。
- 密码哈希参数为 scrypt N=16384、r=8、p=5，采用 [OWASP 提供的 16 MiB 配置](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。Cookie 使用 HttpOnly、SameSite=Lax，HTTPS 时增加 Secure。私有图片和配音响应禁止缓存，避免切换账号后复用上个账号的素材。
- 结构化记录在服务端保存，浏览器存储不作为作品数据源。
- `.openai/hosting.json` 仅声明 DB / ASSETS_BUCKET 逻辑绑定和部署项目标识。数据库迁移位于 `drizzle/`，由 Sites 部署流程应用。
- 请求内容保存时使用 revision 检查；生成完成后读取最新作品，只合并目标镜头或场景的新候选图或配音，因此生成期间的其他编辑不会丢失。
- 已中断的生成任务超过十分钟后会转为可重试失败，避免永久停留在生成中。

## 验证

```bash
npm test
npm run typecheck
npm run lint
npm run build
# 保持开发服务器运行后执行真实 HTTP 验收；非 3000 端口时设置 TEST_BASE_URL
npm run test:integration
```

测试覆盖账号注册登录、密码验证、会话到期与注销、账号数据隔离、旧数据迁移、样例只读保护与副本隔离、分镜时间线、缺图和缺音频位置、字幕与选图变化、播放终点、角色参考图传参、Qwen provider 请求、临时音频地址限制、WAV 校验、配音失败保留、候选图历史保留、重试、并发版本冲突、素材归属与生成恢复。HTTP 验收在默认本地服务上创建两个临时账号并在结束时清理账号记录；指定 TEST_BASE_URL 时不会操作本地数据库。提供商调用在测试中使用受控响应，不会使用真实付费 API；配置真实服务后仍需分别进行端到端生图和配音验收。

人工验收角色一致性时，至少选择同一角色在不同景别、表情和场景中的画面，逐一检查发型、脸部特征、服装和主要配饰。软件会携带参考图，但不能代替该人工验收。
