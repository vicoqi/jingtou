# wan3.0 图生视频使用与提示词构建指南

日期：2026-09-30
状态：调研参考（与 `2026-09-30-wan3-video-roadmap-design.md` 路线图配套）

来源：阿里云官方《万相3.0-视频生成》使用指南 + 《万相3.0视频生成Prompt指南》（中文版），整理并映射到本项目数据模型，供 Phase 1 实现 `buildVideoPrompt` 与调用 `lib/video.ts` 时使用。

## 一、怎么用图生成视频

### 首帧模式（本项目 v1 采用）

```
POST {base}/api/v1/services/aigc/video-generation/video-synthesis
Header: X-DashScope-Async: enable / Authorization: Bearer $DASHSCOPE_API_KEY

{
  "model": "wan3.0-video",
  "input": {
    "prompt": "<camera prompt，见下文>",
    "media": [ { "type": "first_frame", "url": "data:image/png;base64,..." } ]
  },
  "parameters": {
    "resolution": "720P",
    "ratio": "adaptive",
    "duration": 5,
    "audio": true,
    "prompt_extend": false
  }
}
```

- `ratio` 官方建议图生视频设 `adaptive`（自动匹配首帧宽高比）
- `duration` 2–30 任意整数或 `-1` 智能时长
- 首帧图：公网 URL / base64 data URI / OSS 临时 URL 均可（本项目用 base64，R2 私有资产外网不可达）
- 首尾帧模式：加 `{ "type": "last_frame", "url": ... }`，与 `reference_*` 类型互斥

### 图生视频的核心原则（官方原文）

> 用首帧（或首帧+尾帧）锁定画面起止，模型负责补全中间的运动过程。**图像已确定主体、场景与风格，提示词重点描述动态过程、剧情、台词与运镜。**

——验证了路线图的判断：首帧已含一切静态信息，prompt 只写"接下来发生什么"。

## 二、提示词公式（官方完整版）

全模态场景下的完整公式，**想控制什么就写上，写不到的板块直接跳过**：

```
提示词 = [总体描述]
      + [参考素材引用：图 N / 视频 N / 音频 N]
      + [分镜 N（起-止秒）：主体 + 场景 + 运动 + 美学控制]
      + [台词：xx 说："xxxx"]
      + [音效 / BGM]
      + [风格 / 情绪]
      + [负向清单]
```

**首帧模式下的减法**：主体/场景/风格已被首帧图锁定，公式缩减为——

```
视频 prompt = [镜头说明（一镜到底/单镜头）]
           + [时间段分幕：运镜 + 动作/剧情 + 细节]     ← description
           + [台词：角色 + 说话动词 + 引号内容]         ← dialogue + speaker
           + [音效 / BGM（可省，环境音自动匹配）]
           + [风格锚定：沿用图1的xx风格]                ← 防止长视频风格漂移
           + [负向清单]                                 ← 不要字幕/水印等
```

## 三、各要素写法

### 1. 分镜与时间戳

| 想实现什么 | 写法 |
|---|---|
| 单镜头不切分 | 首行写 `生成单镜头` / `一镜到底` / `Generate single shot.` |
| 镜头完全不动 | `固定镜头，摄影机静止，机位不变` |
| 指定运镜 | 大白话即可：`推近`、`拉远`、`环绕`、`手持跟拍`、`镜头快速推进` |
| 镜头内分节拍 | `分镜1（00:00-00:03）：…` / `[0-3秒] …`（序号与时间戳格式不拘，通篇统一） |
| 转场 | 段末 `硬切转场` / `叠化转场`，或下段开头 `从上一分段的最后一帧无缝衔接` |
| 焦段/景深 | `85mm 长焦，浅景深` / `24mm 广角，深焦` |
| 慢动作 | `高速摄影(1000fps 慢动作)` |
| 节奏 | 总体描述里补 `节奏由沉稳压抑转为爆发` |

### 2. 台词（原生音频）

- 格式：**角色 + 说话动词 + 冒号 + 引号内容**。说话动词自带语气：`xx说："…"`、`她低语道："…"`、`将军低沉开口："…"`
- 引用参考图说话：`图1说："xxxx"`、`图2回答："xxxx"`
- 画外音：`画外音："xxxx"` / `女声吟诵："xxxx"`
- 可带时间点：`第 8 秒起，一位空灵温柔的女声缓慢吟诵："…"`
- 无声镜头：`无台词` / `No dialogue.`
- 口型：写台词即自动口型同步，也可显式加 `口型同步` / `Lip sync.`

### 3. 音效 / BGM

- **环境音自动匹配**：画面里写清动作、材质、气象（如 `战旗猎猎`、`积水踩踏`），模型自动补齐对应音效——不必显式列音效
- 指定音效：单独成句，可带时间戳（`色块滑入时'嗖'的 whoosh 壞`）
- BGM 三档控制：
  - 精细：`BGM 转入低音区，大提琴以极轻力度缓缓加入`
  - 粗档：`史诗交响 + 电子音效混合，节奏与镜头切换同步`
  - 关闭：`无 bgm，只生成环境音和动作音` / `No background music.`
- **短剧场景注意**：官方短剧示例普遍写 `不要背景音乐`（BGM 会盖对白）；我们默认关 BGM、保留对白与环境音

### 4. 风格 / 情绪

- 三件套：画风 + 色调 + 情绪，放提示词开头或结尾均可
- 首帧模式下用法是**风格锚定**：`风格说明：整个过程保持图1的水墨画风格…`——防止长视频后段风格漂移
- 关键词参考：画风 `35mm 电影胶片`/`宫崎骏动画`/`国风岩彩画`/`粘土动画`；色调 `高饱和暖黄`/`青蓝×鎏金撞色`；情绪 `悲壮孤峙`/`轻快治愈`/`压抑紧张`

### 5. 负向清单（代替 negative_prompt 参数）

只写不希望出现的内容，不必凑数、不重复正向已写的：

| 类别 | 常用词 |
|---|---|
| 人物/画面 | `不要人脸变形`、`不要人物换脸`、`不要多余手指`、`不要肢体扭曲`、`不要穿模变形`、`不要低清晰度` |
| 文字/水印 | `不要字幕`、`不要水印`、`不要复杂文字` |
| 风格 | `不要低幼卡通`、`不要写实真人风`、`不要游戏 CG 感` |
| 声音 | `不要背景音乐`、`不要人声旁白`、`不要台词`、`不要背景音乐喧宾夺主` |
| 动作 | `不要夸张肢体动作`、`不要人物无逻辑乱跑`、`不要慢动作` |
| 运镜 | `不要大幅运镜`、`不要频繁切镜`、`不要持续镜头抖动` |
| 空间 | `不要空间混乱`、`不要多人同屏`、`不要轴线错乱` |
| 一致性 | `不要人物位置变化`、`不要服装变化` |

### 6. 参考素材引用（首帧模式下仅剩锚定用法）

素材按上传顺序编号，图/视频/音频分别计数（图1 与 视频1 可共存）。首帧模式下没有 reference 素材，唯一用法是风格/主体锚定：`沿用图1的水墨竹林场景`、`保持图1的黑白水墨画风格`。

## 四、官方示例拆解（两份蓝本）

### 蓝本 A：首帧模式·字段化时间分幕（水墨竹林刀客，20s）

```
（0:00-0:03）运镜：中景。
画面：沿用图1的水墨竹林场景。头戴斗笠…的刀客，剪影伫立在浓雾环绕的中心。
动作：刀客左手轻按刀柄，竹叶随风飘落。
氛围：寂静，压抑，水墨晕染的颗粒感清晰可见。

（0:03-0:08）剧情引入，运镜：特写。
剧情：刀客察觉杀气。
细节：斗笠边缘露出一双凌厉、决绝的眼睛…指关节泛白。竹叶飘落的速度加快。

（0:13-0:18）运镜：手持感，高速捕捉。
打斗：刀客猛然拔刀…一击…二击…三击…

风格说明：整个过程保持图1的高度黑白、水墨画风格，动作必须有毛笔触感。
```

要点：**每段一个时间块，块内用「运镜/画面/剧情/动作/细节/氛围」字段化标签**；台词嵌在剧情段（`将军低沉开口："此关，我守了十年。"`）；结尾风格锚定。

### 蓝本 B：短剧·结构化全字段（修仙对白剧，15s，官方短剧最佳实践）

```
视频总时长：15秒
画幅比例：16:9
画风：CG电影风格
核心剧情：
承接上一段最后一帧，叶星辰回到洞府…（完整剧情叙述）
对白：
女内门弟子："叶师弟，苏师姐让你明日辰时去山门前集合。"
叶星辰："何事？"
（一行一句，角色名 + 引号）
图片引用：
图1是叶星辰。图2是女内门弟子。图3是洞府外场景。图4是洞府内场景。
固定空间关系：
开头在洞府内景…叶星辰在左侧，女内门弟子在右侧…（站位/构图约束）
0-2秒：（承接上一段最后一帧，画面+动作）
2-4秒：（脸部近景…）
…
14-15秒：（最后一帧固定为…）
重要要求：
两人不能共用同一张脸…不要字幕、屏幕文字、背景音乐。
```

要点：**头部元信息（时长/画幅/画风）→ 核心剧情 → 对白清单 → 引用说明 → 空间关系 → 时间分幕 → 尾帧定格 → 重要要求（负向）**。

### 多镜头连贯性原则（官方反复强调）

- `每一镜的结束姿势就是下一镜的起始姿势，人物站位、重心朝向、受力方向必须延续，不得瞬移`
- 跨段衔接写 `承接上一段最后一帧`；镜头间写 `从上一分段的最后一帧无缝衔接`
- 对多主体：`两人不能共用同一张脸`、外观锁定各自参考图 `不要混淆、不要互换服装发色`

## 五、buildVideoPrompt 设计建议（映射到本项目数据模型）

结合蓝本 B 的结构与 Shot 现有字段，Phase 1 的 prompt 模板草案：

```
生成单镜头，时长 N 秒，画幅比例 {16:9|9:16}。
画风：{project.style 风格锚定——沿用首帧图风格}。
剧情与动作：
{shot.description —— 镜头内动作过程；较长时可按时间分幕}
{shot.audioLeadIn > 0 时：前 X 秒角色保持静默/停顿}
台词：
{speaker 名}{"说"|voiceInstruction 语气动词}："{shot.dialogue}"
{无对白则写：无台词}
{showSubtitle=false 时负向加：不要字幕}
音效：保留对白与环境音，无背景音乐。
负向清单：不要字幕、不要水印、不要人脸变形、不要肢体扭曲、不要多余手指。
```

与 `buildShotPrompt` 的分工对照：

| | buildShotPrompt（生图） | buildVideoPrompt（视频） |
|---|---|---|
| 静态信息（角色/场景/画风） | 详写（行级结构） | **不写**——首帧图已含，仅留一句风格锚定 |
| dialogue | **排除**（防字幕入画） | **包含**（原生音频需要，注明说话人与语气） |
| description | 消费冻结姿态瞬间 | 消费时间过程（可分幕） |
| 运镜 | 不写 | 写（自然语言：推近/环绕/固定…） |
| 时长 | 不适用 | `duration = clamp(shot.duration, 2, 30)` |

Phase 2 引入 action 字段后：description 归生图（姿态）、action 归视频（过程），storyboard 拆镜时同源生成；尾帧模式加 `从首帧过渡，最后一帧接近图2` 类约束 + `last_frame`。

## 六、任务类型与素材组合速查

| 任务类型 | 触发方式 | 输入 |
|---|---|---|
| 文生视频 | 仅 prompt，不传 media | 支持多镜头叙事 |
| **首帧生视频** | `type: first_frame` | 提示词 + 首帧图（本项目 v1） |
| 首尾帧生视频 | `first_frame` + `last_frame` | 从首帧过渡到尾帧（本项目 Phase 2） |
| 主体/运动/风格参考 | `reference_image`/`reference_video` | 图≤10 / 视频≤5 段≤15s，可任意组合 |
| 音频参考 | `reference_audio` | 音频≤5 段≤15s（音色克隆：`音色参考音频1`） |
| 视频编辑 | `reference_video` + 编辑意图词 | 增删改元素、风格/台词编辑 |
| 视频延长 | `reference_video` + 延长意图词 | 前/后/双向延续 |
| 文件/网页生视频 | `file` 或 `link`（各限 1，互斥） | 解析文档/公开网页生成视频 |

硬规则：`first_frame`/`last_frame` 与 `reference_*`/`file`/`link` **互斥**，不可混用。
