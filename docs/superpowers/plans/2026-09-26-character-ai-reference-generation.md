# Character AI Reference Generation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a signed-in creator generate one to four character reference images from a character draft using the project's existing image provider and visual style.

**Architecture:** Add a character-specific prompt builder and a private project endpoint that validates the draft, calls the existing OpenAI-compatible image generation adapter, stores generated bytes in the user's asset bucket, and returns normal `ReferenceImage` objects. The character modal calls this endpoint after pending project edits are flushed, appends returned images to the draft, and lets the creator remove images before saving the character.

**Tech Stack:** TypeScript, React 19, vinext/Cloudflare Worker, D1, R2-compatible asset bucket, Node test runner.

## Global Constraints

- Reuse `IMAGE_API_BASE_URL`, `IMAGE_API_KEY`/`OPENAI_API_KEY`, and `IMAGE_MODEL`; add no second image-provider configuration.
- Generated character images remain private to the authenticated account.
- A character keeps at most 20 reference images; one generation request creates 1–4 images.
- The bundled sample project remains read-only.
- The character draft must have both a name and an appearance description before generation.
